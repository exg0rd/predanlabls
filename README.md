# Лабораторная работа №2
## Виртуальный датчик концентрации продукта обжига

Решение: [`lab2_virtual_sensor.ipynb`](lab2_virtual_sensor.ipynb) - полный пайплайн EDA,
инжиниринга признаков, обучения и оценки моделей.

### Исходные данные

Четыре CSV-файла лежат в корне репозитория:

- `data_train.csv` - минутная телеметрия за 8 месяцев (16 каналов);
- `target_train.csv` - нерегулярные лабораторные замеры целевого показателя;
- `data_test_small.csv`, `target_test_small.csv` - отложенный тестовый период.

CSV исключены из Git из-за размера. Ноутбук читает их из текущей папки.

### Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

jupyter notebook lab2_virtual_sensor.ipynb
```

Ноутбук уже выполнен, все графики и метрики сохранены в выходах ячеек.

### Кратко о решении

1. **EDA.** Удалены дубликаты меток времени, исключены почти пустые каналы
   `telemetry_12..15`, короткие пропуски интерполированы. Целевой показатель измеряется
   в основном раз в 2 часа (1773 замера), имеет правоскошенное распределение и дискретную
   сетку с шагом `1/97`.
2. **Синхронизация.** Лабораторный результат приходит с задержкой 10-15 минут. Текущий
   замер исключён из признаков; используются телеметрия до момента `t` и предыдущие
   лабораторные значения.
3. **Признаки.** Лаги телеметрии (0-120 минут), скользящие mean/std/min/max (5-240 минут),
   приращения, календарные признаки и история target. Итого 423 признака, далее отбор
   по F-тесту.
4. **Модели.** Ridge-регрессия, ExtraTrees, HistGradientBoosting; базовые стратегии -
   persistence и скользящее среднее.

### Результаты на тесте

| Модель | MAE | RMSE | MAPE, % | WAPE, % | Direction acc. |
|---|---:|---:|---:|---:|---:|
| **Ridge (CV)** | **0.0518** | **0.0667** | 28.48 | **24.69** | 0.689 |
| HistGradientBoosting | 0.0524 | 0.0680 | 27.72 | 24.97 | 0.709 |
| ExtraTrees | 0.0537 | 0.0684 | 29.88 | 25.62 | 0.712 |
| Скользящее среднее | 0.0554 | 0.0746 | 27.91 | 26.40 | 0.599 |
| Persistence | 0.0595 | 0.0801 | 29.72 | 28.37 | - |

Лучшая модель по WAPE - Ridge: относительно persistence ошибка снижается примерно на 13%.
Основной вклад в прогноз дают лаги и скользящие средние target, затем `telemetry_0`,
`telemetry_3` и `telemetry_6`.

### Ограничения

- Сигнал телеметрии в мгновенной связи с target слабый (|r| до 0.19), поэтому значимая
  часть ошибки - шум лабораторных измерений.
- Остатки ненормальны и гетероскедастичны; автокорреляция остатков на лагах 6 и 12
  статистически не значима.
- Тестовый период короткий (318 замеров), модель обучена на одном режиме печи.
  Для промышленного внедрения нужны мониторинг дрейфа и периодическое переобучение.

Файл [`predictions_test.csv`](predictions_test.csv) содержит фактические значения и
прогнозы всех моделей на тестовом периоде.
