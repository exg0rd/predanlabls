# Лабораторная работа №2
## Виртуальный датчик концентрации продукта обжига

Решение: [`lab2_virtual_sensor.ipynb`](lab2_virtual_sensor.ipynb) - пайплайн EDA,
инжиниринга признаков, обучения и оценки моделей.

### Исходные данные

Четыре CSV-файла лежат в корне репозитория:

- `data_train.csv` - минутная телеметрия за 8 месяцев (16 каналов);
- `target_train.csv` - нерегулярные лабораторные замеры целевого показателя;
- `data_test_small.csv`, `target_test_small.csv` - отложенный тестовый период.

CSV исключены из Git из-за размера. Ноутбук читает их из текущей папки.

### Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

jupyter notebook lab2_virtual_sensor.ipynb
```

### Структура решения

1. EDA и синхронизация телеметрии с лабораторными замерами.
2. Инжиниринг временных признаков: лаги, скользящие статистики, приращения,
   календарные признаки, история target.
3. Модели: Ridge-регрессия, ExtraTrees, HistGradientBoosting и базовые стратегии.
4. Оценка качества, анализ остатков и важности признаков.
